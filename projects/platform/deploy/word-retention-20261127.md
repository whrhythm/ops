# 正式聊天 Word 交付记录 · 2026-11-27

**用户任务。** 关闭聊天、临时执行会话过期后，回到原回复仍能预览和下载当时生成的 Word。

**用户入口。** 正式办公任务返回 Word 后，平台将工作副本放入该账号的「个人文件 → 聊天文档」，并写入个人文件既有格式的第一版快照。会话回执绑定该版本。编辑工作副本后，原回执仍返回交付时的字节。首次保存遇到存储错误会返回“尚未保存”，再次读取任务详情或重试同一任务只补保存。

**实现和发布。** 平台沿用原有任务、账号文件服务和文件配额。创建采用禁止覆盖的写入方式，重试校验内容摘要。读取时核验签名身份、所属环境和保存的摘要。生产工作负载为 `platform-system/platform-api` 的 `api` 容器。本次仅更新在线镜像引用。

**验收。** 在候选镜像运行办公任务、执行网关、模型额度及 Word 交付回归，74 项通过，4 项跳过。专项测试覆盖首次保存空间不足、同一任务重试、执行端关闭且临时回执过期后下载、编辑工作副本、快照损坏和跨账号请求。

生产专用 QA 账号通过服务接口真实执行一次 DOCX 生成，经原回执下载 36,604 字节。历史故障单涉及的文件通过持久所有权记录、登录身份、任务回执和对象标识交叉核验，恢复两个回执引用的同一份原件。保存前后 SHA-256 一致，生产 Word 渲染器返回两页。验收范围为服务和渲染链路，尚未独立执行登录浏览器后的点击验收。

**异常与回退。** 首次切换因节点缺少 pause 镜像且旧代理超时触发自动回退。缓存并固定该节点需要的 pause 镜像后，第二次切换成功，就绪检查通过。Argo CD 仓库连接仍需单独修复。代码回退可使用上一版 API 镜像；个人空间已经写入的文档和版本应保留，旧版 API 无法解析新增的快照回执。
